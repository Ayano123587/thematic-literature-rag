# Real QA benchmark provenance

NarrativeQA: Kočiský et al. (2018), *The NarrativeQA Reading Comprehension Challenge*, https://aclanthology.org/Q18-1023/. Source: https://github.com/google-deepmind/narrativeqa, pinned commit `904246f6d1fe99a99a08a03501fe3e619af2cee5`. The repository metadata and QA annotations are Apache-2.0 licensed. The downloader preserves the original LICENSE and README locally. Wikipedia summaries have separate attribution conditions and are not downloaded, indexed or redistributed here.

Neither *Pride and Prejudice* nor *Frankenstein* is present in the published NarrativeQA document list. This was checked before selecting the compatible Gutenberg expansion. NovelQA was considered but has gated contact-sharing/access terms, which were not accepted. Instead, the adapter adds *The Picture of Dorian Gray* (Gutenberg 174; Oscar Wilde died 1900) and *Persuasion* (Gutenberg 105; Jane Austen died 1817). Check local copyright law before downloading. No book text or QA CSV is committed.

The official Dorian document `879287f285743b08d86c3bd0831ec1e49fa92e39` supplies all 29 matching validation questions. Persuasion document `55d68540c6b86bc90f7a9e630c8b13c0920bf834` supplies all 29 matching test questions. No question or answer was filtered by retrieval success. Gold answers remain local. Question IDs refer to stable row ordinals of the pinned qaps.csv. [narrativeqa-source-manifest.json](narrativeqa-source-manifest.json) records upstream URLs, SHA-256 hashes, Gutenberg raw hashes and normalized processed-text hashes.

A subsequent independent audit found that the first processed-hash fields described prewrite bodies, not actual persisted text. On Windows, native CRLF translation preserved existing CR and expanded LF, producing doubled normalized line breaks. [provenance-audit.json](provenance-audit.json) preserves the original fields and records corrected actual-byte and actual-read_text digests. Existing source files, indexed text, predictions and live cloud payload were not changed. All 2,605 passages in both original indexes and all 236 cloud payload passages matched exact current source slices. The source writer now explicitly freezes the same CRLF-v1 representation across operating systems; temporary-file tests proved byte-identical replay of the three audited existing sources. Hashes are computed after writing. A later canonical-text migration must declare a new representation version and rebuild citation offsets.

The first benchmark archives predated embedded model-revision metadata. Their exact numeric-array digests and cache-observed revisions are retained in the provenance audit; the old archive itself does not attest its revision. Production persistence now requires an exact model revision. Revisionless neural archives are refused, with a separate forensic-only option that cannot encode queries. The historical artifact is preserved locally and compared against explicitly pinned re-encoding in [embedding-pin-audit.json](embedding-pin-audit.json); numerical equality cannot rewrite its original provenance. No frozen cloud payload, policy or benchmark test is changed by this audit.

Only the four novels' original processed text is indexed. No QA answers, Wikipedia summaries or answer-bearing benchmark annotations are inserted into passages. TF-IDF/LSA is fitted transductively on the searchable corpus, including the test novel's text, as a retrieval index requires access to source documents. Pretrained MiniLM embeddings, MS-MARCO reranker and SQuAD2 reader are not finetuned on these QA labels. Validation chooses retrieval and abstention policies; the official test questions are retrieved only after those selections are serialized. This is query/document split separation, not a claim that pretrained model corpora never contained these public novels.

NarrativeQA questions were crowdsourced from summaries, so answers may be paraphrases or absent from a particular book edition. Gold answer content-token recall and literal answer presence are only lexical evidence proxies. Actual extractive answer token F1 and exact match are separately evaluated. The two-book subset is small and narrow; no full-NarrativeQA leaderboard comparability, independent thematic interpretation, or universal no-answer calibration is claimed.
