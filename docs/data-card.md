# Corpus and rights

The downloader uses Project Gutenberg IDs 1342 (Jane Austen, Pride and Prejudice; author died 1817) and 84 (Mary Shelley, Frankenstein; author died 1851). These editions are offered by Gutenberg as public-domain works in the USA. This is not a universal copyright determination. Check your local law before downloading or reuse. The CLI requires explicit local-rights acknowledgment. No book text is committed.

Primary policy: https://www.gutenberg.org/policy/license and https://www.gutenberg.org/policy/permission. Raw downloads preserve the full included Gutenberg license. Processing requires expected START/END boundaries and records source URL, byte count and SHA-256 in data/external/manifest.json. Gutenberg files can change; the manifest describes the exact local run, not a guarantee that future downloads match. Compare manifests for reproducibility.

The small corpus overrepresents nineteenth-century English prose and cannot establish multilingual or general literary analysis capability. Character search uses explicit name mentions and misses pronouns, aliases and implicit references.
